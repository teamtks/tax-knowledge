# tax-knowledge — 税法の一次情報キャッシュ

**日本の税法の条文と法令解釈通達を、機械が引ける形に整えて保管しているリポジトリです。**
e-Gov法令API（デジタル庁）と国税庁サイトから自動で取得しており、
**人が要約や解説を書き加えていません。**

収録しているのは**原文だけ**です。解釈・要約・判断は含みません。

---

## なぜ原文しか置かないのか

このリポジトリは、AI（Claude）が税務の検討をするときに条文を引くための土台です。
そこで一点だけ、はっきり決めています。

> **AIが書いた要約を、人の検証を経ずに保管しない。**

AIの記憶から書いた「◯◯法◯条によれば〜」は、条番号ごと誤っていても一見もっともらしく読めます。
一方、APIから取得した条文原文は、検証が要りません。**原典そのものだからです。**

そのため、このリポジトリに入るのは取得した原文と、その出所だけです。

## フォルダの構成

```
law/<法令ID>/
├─ _meta.json                    法令番号・リビジョンID・施行日・条の一覧
├─ README.md                     条番号と見出しの索引（人が読む用）
├─ articles/At_<条番号>.md        本則の条文（1条1ファイル）
├─ suppl/<改正法令番号>.md         附則（改正法ごとに1ファイル）
└─ appendix.md                   別表・様式その他

tsutatsu/<コード>/
├─ _meta.json                    通達名・項目一覧・出典URL
├─ README.md                     通達番号と見出しの索引（人が読む用）
└─ items/<通達番号>.md            通達（1項目1ファイル）
```

条番号は e-Gov API の記法に合わせています。`At_22_2.md` は第22条の2です。

**附則を条単位に分けていないのは意図的です。** 附則は「この改正法の経過措置」としてまとめて
読むものだからです。なお、インボイス制度の2割特例や80%控除の経過措置は
**改正法の附則**にあります（例: `law/363AC0000000108/suppl/平成二八年三月三一日法律第一五号.md`）。

## 引き方

人が読むときは `law/<法令ID>/README.md` の索引から辿ってください。

機械から引くときは `index.json` → `_meta.json` → 条文ファイル、の順に辿れます。
法人税法22条であれば `law/340AC0000000034/articles/At_22.md` です。

**過去の時点の条文が必要なときは、このリポジトリではなくAPIを直接引いてください。**
施行日を指定して取得できます。

```
https://laws.e-gov.go.jp/api/2/law_data/340AC0000000034?elm=Mp-At_22&asof=2024-04-01
```

このリポジトリが保持しているのは**現在施行されている版だけ**です。
過去の事業年度を扱うときは `asof` が必要になります。

## 更新の仕組み

GitHub Actions が収集スクリプトを自動で実行します。

| 対象 | 頻度 | 所要 | 理由 |
|---|---|---|---|
| 法令 | **毎日** JST 3:00 | 約30秒 | e-Gov API なので軽い |
| 通達 | **週1回** 日曜 JST 3:00 | 約20分 | 国税庁サイトを約700ページ辿るため、負荷に配慮して0.8秒間隔 |

```
収集スクリプトを実行
  → 中身が変わったファイルだけ書き換わる
  → 差分があれば commit & push、無ければ何もしない
```

収集スクリプトを変更して push したときも実行されます（動作をその場で確かめるため）。

**取得日時をファイルに書き込んでいません。** git のコミット日時が取得日時です。
これにより、改正が無い日は差分がゼロになり、履歴が無駄に太りません。

改正の有無だけを確認したいときは、本文を取得せずに調べられます（1法令あたり数KB）。

```bash
python collectors/egov_law.py --check
```

### 「いつの条文で判断したか」が残ります

git の履歴に、どの版の条文がいつから入っていたかが記録されます。
後から「この判断は令和◯年◯月時点の条文に基づく」と確認できます。

## 出典と法的な位置づけ

| 内容 | 出典 | 利用条件 |
|---|---|---|
| 法令 | **[e-Gov法令検索](https://laws.e-gov.go.jp/)**（デジタル庁） | APIは利用登録・認証を要さず無償 |
| 通達 | **[国税庁 法令解釈通達](https://www.nta.go.jp/law/tsutatsu/menu.htm)** | [政府標準利用規約準拠](https://www.nta.go.jp/chuijiko/copy.htm)。出典明示のうえ複製・加工可 |

法令は、**著作権法第13条第1号**により著作権の目的となりません。

> 次の各号のいずれかに該当する著作物は、この章の規定による権利の目的となることができない。
> 一　憲法その他の法令

同条第2号は「国若しくは地方公共団体の機関……が発する**告示、訓令、通達**その他これらに類するもの」、
第3号は「裁判所の判決、決定、命令及び審判……」を挙げています。
**通達が明示されている**ため、本文をそのまま保管しています。

## 免責

- **このリポジトリは機械的な写しです。** 原典は e-Gov法令検索（法令）と国税庁サイト（通達）です。
  実際の税務判断に用いる際は、必ず原典で確認してください。
- 取得・整形の過程に不具合がありうるため、条文の完全性・正確性を保証しません。
- 収録しているのは**現在有効な版のみ**です。過去の時点の条文・通達は含まれません。
  インボイス制度前など過去の通達が必要な場合は、国税庁サイトの日付付きアーカイブ
  （例 `/kihon/shohi/20230930/`）を直接参照してください。
- **判例・裁決・会計基準は含まれていません**（別途取り込む予定です）。
- 通達は主要4種のみです。国税通則法基本通達と措置法通達（消費税編）は
  ページ構造が異なるため未対応です（`config/tsutatsu.json` に理由を記載）。
- このリポジトリは条文を提供するだけで、税務上の助言を行うものではありません。

## 収集スクリプトについて

収集スクリプトは Python 標準ライブラリのみで動きます。`pip install` は不要です。

```bash
# 法令
python collectors/egov_law.py                     # config の有効な法令を収集
python collectors/egov_law.py --law 340AC0000000034
python collectors/egov_law.py --check             # 改正の有無だけ調べる（数KBで済む）
python collectors/egov_law.py --resolve 会社法     # 法令名から法令IDを調べる

# 通達
python collectors/nta_tsutatsu.py                 # config の有効な通達を収集
python collectors/nta_tsutatsu.py --code hojin-kihon
```

**これらのスクリプトはAIを使いません。** 取得と整形だけを行うため、
スケジュール実行だけで完結します。
