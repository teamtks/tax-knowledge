# 公表裁決事例要旨　印紙税法関係

> 出典: 国税不服審判所（https://www.kfs.go.jp/service/MP/08/index.html）。政府標準利用規約に基づき、出典を明示して複製・加工している。法令・通達・判決・裁決は著作権法13条により著作権の目的とならない。

4件。


## 課税物件 ＞ 非課税物件

- [駐車場等として賃貸していた土地の譲渡に係る受取書は、非課税となる「営業に関しない受取書」に該当しないと判断した事例](0201000000.md)　平成18年9月29日

## 課税物件 ＞ 請負に関する契約書

- [請求人が売買の目的とした養鶏機器の据付工事を行う旨の記載のない見積書等と一体となった売買契約書は、印紙税法上の「請負に関する契約書」には該当せず、他方、据付工事](0202000000.md)　平成22年9月8日
- [顧客から商品の返品若しくは交換又は売価が異なるなどの申出を受けた際に使用する「お客様返金伝票」と題する伝票のつづりは、印紙税法上の「判取帳」に該当するとした事例](0203000000.md)　平成26年10月28日

## その他 ＞ 過誤納

- [印紙税の過誤納の事実を確認すべきである旨の請求人の主張が、請求人が署名押印し銀行に差し入れた時に本件契約書に係る印紙税の納税義務は成立しているから、印紙税の過誤](0101000000.md)　平成12年1月26日
