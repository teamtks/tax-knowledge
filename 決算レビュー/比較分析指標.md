# 比較分析指標

決算レビューの**②過去期との比較**と**③改善提案**で使う指標の定義と閾値。

> [!note] ここは税法ではなく分析の約束事である
> 条文の裏取りは不要だが、**閾値は事務所として決めるもの**である。
> 初期値は暫定で置いてある。運用しながら「拾いすぎる／拾えない」を見て調整すること。
> 閾値を変えたらこのノートを更新し、更新日を残す。

## 比較の期間

**原則3期**（当期・前期・前々期）。それ以上は読まれない。
ただし次の場合は5期に伸ばす。

- 繰越欠損金があり、期限切れの判定が要る
- 消費税の拘束期間（2年・3年）の起算を追う必要がある
- 設備投資の周期を見たい

## 数値の出所

| 項目 | 出所 | 確度 |
|---|---|---|
| 当期の科目別残高 | 仕訳日記帳・総勘定元帳PDFの集計（決算レビューのプログラム） | 決算確定後なら **確定** |
| 前期・前々期 | 顧問先データ保管庫の `数値履歴` | `数値履歴` の確度欄に従う |
| 申告書の数値（別表・付表） | 申告書PDF | **確定**。ただし人の検算を経るまで「未検算」扱い |

**比較表には必ず出所と確度を併記する。** 暫定値と確定値を並べて増減率を出すと誤った結論になる。

## 1. 損益の指標

| 指標 | 算式 | 「要説明」とする条件（暫定） |
|---|---|---|
| 売上高 | — | 前期比 ±15% 以上 |
| 売上総利益率 | 売上総利益 ÷ 売上高 | 前期比 ±3ポイント 以上 |
| 営業利益率 | 営業利益 ÷ 売上高 | 前期比 ±3ポイント 以上 |
| 経常利益率 | 経常利益 ÷ 売上高 | 前期比 ±3ポイント 以上 |
| 人件費率 | （役員報酬＋給与手当＋法定福利費＋福利厚生費）÷ 売上高 | 前期比 ±3ポイント 以上 |
| 販管費率 | 販管費 ÷ 売上高 | 前期比 ±3ポイント 以上 |
| 減価償却費 | — | 前期比 ±20% 以上（設備投資・除却との整合を見る） |

### 科目別の増減

**売上総利益率や営業利益率が動いたら、必ず科目別まで降りる。** 率だけ示しても原因が分からない。

| 条件 | 扱い |
|---|---|
| 前期比 **±20%以上 かつ ±100万円以上** の増減 | **要説明**。原因を1行で書く |
| 前期になく当期に発生した科目 | **要説明**。新規取引・新規契約の確認 |
| 前期にあり当期に消えた科目 | **要説明**。計上漏れの可能性 |

> 「±20%以上 **かつ** ±100万円以上」の両方を課すのは、小さい科目のノイズを落とすためである。
> 規模の大きい顧問先では金額基準を引き上げる。

## 2. 財政状態の指標

| 指標 | 算式 | 「要説明」とする条件（暫定） |
|---|---|---|
| 売掛金回転期間 | 売掛金 ÷ 月商 | 前期比 +0.5か月 以上 |
| 棚卸資産回転期間 | 棚卸資産 ÷ 月売上原価 | 前期比 +0.5か月 以上 |
| 買掛金回転期間 | 買掛金 ÷ 月仕入 | 前期比 ±0.5か月 以上 |
| 自己資本比率 | 純資産 ÷ 総資産 | 低下、または 10% 未満 |
| 流動比率 | 流動資産 ÷ 流動負債 | 100% 未満 |
| 借入金月商倍率 | 有利子負債 ÷ 月商 | 6か月 超 |
| 債務償還年数 | 有利子負債 ÷（税引後利益＋減価償却費） | 10年 超 |

> 回転期間の悪化は、**架空売上・不良債権・滞留在庫**のいずれかを疑う入口になる。
> ①のチェック（3-3 売掛金の滞留、4-1 期末棚卸）と突き合わせること。

## 3. 税務固有の推移

**ここが一般の財務分析と違う部分であり、この事務所にとって価値のある部分である。**

| 項目 | 見るもの | なぜ見るか |
|---|---|---|
| 課税売上高の推移 | 3期分 | **1,000万円・5,000万円の基準を跨ぐ期**を予告するため |
| 課税売上割合の推移 | 3期分 | 95%を割り込む兆候。個別対応方式の準備 |
| 特定期間の課税売上高・**給与等支払額** | 前期上半期 | 給与基準で課税事業者を回避できる場合がある |
| 本則課税と簡易課税の実績比較 | 当期の実額で両方を試算 | **翌期の届出判断の材料**。③に直結する |
| 所得金額の推移 | 3期分 | 軽減税率の800万円ライン、繰越欠損金の消化見込み |
| 繰越欠損金の残高と発生期 | 各期 | **期限切れで消える期を予告する** |
| 国内雇用者給与等支給額 | 3期分 | 賃上げ促進税制の増加率判定 |
| 交際費の推移 | 3期分 | 800万円ラインへの接近 |
| 固定資産の取得履歴（1件100万円以上） | 3期分 | **消費税の拘束期間の起算**。①9-7と同じ |

### 基準額に接近しているかの判定

次に該当したら、**③改善提案に必ず項目を立てる**。

| 基準 | 「接近」とする範囲（暫定） | 効果 |
|---|---|---|
| 課税売上高 1,000万円 | 800万〜1,200万円 | 免税／課税の切替わり |
| 課税売上高 5,000万円 | 4,000万〜6,000万円 | 簡易課税の可否 |
| 課税売上割合 95% | 93%〜97% | 仕入税額控除の方式選択 |
| 所得金額 800万円 | 600万〜1,000万円 | 軽減税率の適用範囲 |
| 交際費 800万円 | 700万円超 | 定額控除限度額の超過 |
| 資本金 1,000万円／1億円 | — | 該当したら即記載 |

## 4. ③改善提案の組み立て

提案は**「気づき」ではなく「次の行動と期限」**にする。

| 提案の型 | 書くこと | 落とし先 |
|---|---|---|
| **届出で有利になる** | 有利額の試算、届出名、提出期限 | **顧問先データ保管庫の `10_期限管理/` に期限ノートを起票（必須）** |
| **経理処理を変える** | 現状の処理、変えた後の処理、いつから | 顧問先ノートの「判定時の注意点」に追記 |
| **資料の取り方を変える** | 不足している証憑（飲食費の人数記録など） | 同上 |
| **基準額に近づいている** | 何期後に跨ぐ見込みか、跨ぐと何が変わるか | 期中判定の時期を前倒しする |
| **財務体質** | 指標の推移と改善余地 | レポートのみ（税務ではないため断定しない） |

> [!danger] 提案を文章で終わらせない
> 「翌期は簡易課税が有利と思われます」と書いただけのレポートは、**期限を過ぎてから読まれる**。
> 届出が絡む提案は、例外なく顧問先データ保管庫の `10_期限管理/` に `確度: 要確認` で起票する。
> 顧問先が出さないと決めたら `状態: 不要` にすればよい。**起票しない選択肢はない。**

## 5. レポートに書いてはならないこと

- **原因の断定。** 「売上総利益率の低下は原価管理の失敗による」と書かない。
  「低下している。原因の確認をお願いしたい」と書く。
- **経営判断への踏み込み。** 借入・投資・人員の助言は税理士業務の範囲と依頼内容を確認してから。
- **同業他社比較の数値を出所なしに書く。** 統計を引くなら出典（TKC BAST、中小企業実態基本調査等）を明示する。
