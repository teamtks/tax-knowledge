# 決算チェックリスト（法人）

決算確定後・申告書提出前に、**仕訳日記帳・総勘定元帳・固定資産台帳と申告書・決算書から「合理性に欠ける部分」を拾う**ための項目表。

> [!danger] このノートは未検証である
> 条文番号・金額基準は AI が整理した草案であり、担当税理士のレビューを受けていない。
> **1項目ずつ原典で裏を取り、`検証` 欄にチェックを入れること。**

## 表の読み方

| 欄 | 意味 |
|---|---|
| 検出 | **機** = 帳簿（仕訳日記帳・元帳・台帳）から機械的に拾える／**人** = 人が資料を見ないと判断できない／**突** = 申告書と帳簿の両方の数字で突き合わせる。括弧内はプログラムの判定ルールの番号（`checks.json`） |
| 検出条件 | 決算レビューのプログラムが抽出する条件、または Claude が探す条件 |
| 疑う内容 | それが出たときに何を疑うか |
| 根拠 | 当たるべき条文・通達（**全て要確認**） |

**「機」の項目でも、拾ったものが直ちに誤りとは限らない。** 抽出は「説明を求める対象」を絞る作業であり、
正否の判断は人が行う。レビューレポートには**必ず「検出」と「判定」を分けて書く**こと。
